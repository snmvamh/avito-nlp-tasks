# Кандидатогенерация в поиске услуг

По поисковому запросу надо выбрать из базы до 50 объявлений. Метрика Recall@50.

Всё решение в файле `avito_candgen.ipynb`. Он выполняется сверху вниз и в конце записывает `answer.csv`.

## Как работает

Для каждого объявления считается оценка из четырёх частей, берутся 50 лучших

* бонус за локацию
* BM25 по тексту объявления
* вероятность микрокатегории по тексту запроса
* близость эмбеддингов

Бонус за локацию намного больше остальных, поэтому объявления своего города всегда впереди, а внутри города порядок решают текст и микрокатегория. При этом ничего не выбрасывается, все 50 мест заполняются всегда.

У части запросов локации поиска нет среди локаций объявлений. Для них по train построена карта, куда обычно уходили клики из этой локации.

## Результат

Recall@50 на своей проверке около 0.89. Как набирался, видно в ноутбуке

* только слова, около 0.27
* плюс локация, около 0.80
* плюс микрокатегория, около 0.83
* плюс эмбеддинги, около 0.89

Локация даёт основной прирост. На платформе цифра ниже, потому что в проверке часть правильных ответов не попадает в базу

## Как устроена проверка

Проверять идеи отправками нельзя, попыток всего 7. Поэтому своя проверка собрана из train, там ответы известны. Объявления взяты из базы бенчмарка, а запросы и ответы к ним из train. Запросы, попавшие в проверку, удалены из обучения, иначе модель их запомнит. Запросы поделены на знакомые и новые в той же пропорции, что в бенчмарке

## Что использовано

* pandas, numpy, scipy
* scikit-learn, из него CountVectorizer, TfidfVectorizer, ComplementNB
* sentence-transformers и datasets
* pyarrow

Модель эмбеддингов `intfloat/multilingual-e5-small`, лицензия MIT, запускается локально. Готовая модель про услуги ничего не знает, поэтому дообучена на парах «запрос и выбранное объявление» из train. Дообучение дало примерно плюс 0.014 к метрике.

BM25 написан самостоятельно, готовые реализации слишком медленные для 189 тысяч объявлений.

Готовых решений задачи не использовала. Под конкретные query_id ничего не прописано

## Как запустить

```
python3 -m venv --system-site-packages .venv
.venv/bin/python -m pip install -r solution/requirements.txt
.venv/bin/python -m ipykernel install --user --name avito-venv
```

Дальше открыть `solution/avito_candgen.ipynb` и выполнить все ячейки. Файлы parquet должны лежать на уровень выше ноутбука.

Первый запуск занимает около часа, из них полчаса дообучение модели и десять минут кодирование объявлений. Результаты сохраняются в папку `work`, при повторном запуске берутся оттуда и всё проходит за пару минут. Дообучение заметно быстрее на видеокарте, код сам её найдёт, если она есть.

Всё считается локально. Модель эмбеддингов скачивается один раз при первом запуске, дальше работает без сети.
